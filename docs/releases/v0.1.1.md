First public Windows release of FileEncrypt.

- Encrypt, verify, restore, and rotate files and folder ZIP bundles.
- Preview files with the saved key connected, including image zoom and the updated audio player.
- Updated explorer icons and improved performance for large selections.
- Generate sandbox CSS and script security hashes automatically.

Download `FileEncrypt_0.1.1_x64-setup.exe` to install on Windows x64. Keep a separate backup of your file-encryption key.

The installer is signed for FileEncrypt's updater. It does not have a Windows publisher code-signing certificate.
