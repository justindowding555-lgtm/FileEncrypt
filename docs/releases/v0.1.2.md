Fixes for the window layout and selected-file summary.

- Cover the full window with dialog backdrops, removing the light strips along both sides.
- Show separate counts for files ready to encrypt, verified encrypted files, pending verification, and failed verification.

Use **Check for updates** in version 0.1.1, or download `FileEncrypt_0.1.2_x64-setup.exe` for Windows x64.

The installer is signed for FileEncrypt's updater. It does not have a Windows publisher code-signing certificate.
